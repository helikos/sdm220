# Почему библиотека лежит в репозитории

`ayushsharma82/AsyncElegantOTA` удалён из реестра PlatformIO (автор перевёл
проект в ElegantOTA v3 с другой моделью лицензирования). Строка

    ayushsharma82/AsyncElegantOTA @ ^2.2.5

в `lib_deps` больше не разрешается: `UnknownPackageError`. То есть собрать
проект с чистого клона было невозможно - работали только машины, где пакет
уже лежал в `.pio/libdeps/`.

Версия 2.2.5, лицензия MIT (см. LICENSE), скопирована как есть.

Варианты уйти от вендоринга:
  * `ESPAsyncHTTPUpdateServer` - живой аналог, API близкий;
  * `ElegantOTA` v3 - продолжение этой же библиотеки, но у v3 другая лицензия
    (часть функциональности платная);
  * `Update.h` из ядра ESP32 + свой обработчик на AsyncWebServer.

ВАЖНО: OTA-эндпоинт по-прежнему без аутентификации (пункт 2 обзора).
`AsyncElegantOTA.begin(&server, user, pass)` закрывает это одной строкой.
